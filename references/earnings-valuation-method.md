# 财报驱动的营收与PS模型

目录：数据契约｜预测｜估值与历史Band｜归因｜更新和证伪｜运行与迁移。

## 数据契约

- 金额统一人民币元，展示时才转亿元；股本用股，价格元/股。口径固定为合并营业收入（含其他业务、不含增值税）、权益总市值；不混用主营收入、母公司收入、流通市值或EV/Sales。
- 每个报告记录报告期、累计月数、公告日期、审计状态、来源URL、页码/表名、下载原件SHA256、提取时间及修订版本。关键行人工对照原件，OCR数字不能直接入模。
- 事实为数值或null；null同时记录原因：未披露、未取得、口径冲突、不适用。预测独立标记analyst_assumption，不能填回事实表；传闻不能进入模型。
- 累计流量用Q2=H1-Q1、Q3=9M-H1、Q4=FY-9M。毛利率必须先差分收入和成本再计算；不能差分两个毛利率。资产负债是时点余额，不做季度相加。缺前一累计期则单季度为null。
- 净研发费用、研发投入、资本化研发和股权支付分别核对。可比不清时不把研发费率下降当盈利兑现。经营现金流、销售回款、税费返还分别列示；销售回款通常含税、含预收、含历史应收，不能直接当本期收入。
- 订单指标注明：新签/在手、含税/不含税、是否取消可撤销、是否含已确认收入、合并范围、时点/期间、是否包含服务和海外订单。
- 存货是成本，发出商品也常为成本；不能直接加到销售额。合同负债是客户对价义务，既非订单总额，也不能与订单、发出商品简单相加。

## 两条预测路径

### A. 可验证的验收队列（优先）

将互不重叠的期初待验收设备、期初未交付订单、当年新订单、服务/其他分别建队列：

`R(nextFY,q) = Σ[队列不含税销售额 × 该季度验收占比] + 服务及其他(q)`。

每个队列有唯一ID、源文件、销售额口径和季度验收权重，四季度权重之和≤100%。若输入是存货成本，先在独立分析中给定可比产品毛利率、可售比例、跌价/取消假设，估算`成本/(1-产品毛利率)×可售比例`，标为假设；不得用公司综合毛利率冒充产品合同价格。期初队列在预测年度之前已验收部分先剔除，新签订单不得重复计入期初订单。ID只能防止技术上的重复，分析师仍须检查经济上的重叠。

对新签订单建立客户资本开支、供应份额、产能、交付和验收的交叉校验。无法量化的客户验证只列催化，不直接赋收入。至少核查一次采购/制造产能是否足以支撑乐观情景。

### B. 季节性收入路径（数据不足时）

缺订单销售额、队列或验收周期时，明确降为**条件情景/screen-grade**，不能宣称订单覆盖预测：

1. 汇总最近2—3年季度结构，核对验收政策和年末集中度。
2. 保留当前年已披露Q1—Q3原值；`Q4估计=上年Q4×(1+Q4同比假设)`。
3. `下一年各季度收入=当前年对应季度(实际/估计)×(1+逐季增长假设)`，四季相加；不能单季度×4、9M÷3×4或将合同负债增速当收入增速。
4. 悲观/基准/乐观各自注明增长由验收速度、产品组合、客户需求变化中的什么驱动。可用“当前增长延续”作为基准锚，但它依然是假设，不是公司指引。
5. 列示季度/年度增长、Q4占比、毛利率与研发费用敏感性；缺费用/税收等证据不输出精确净利润。预测范围应随证据变化，不固定所有公司20/35/50%。
6. 队列法与季节性法若均可运行，比较差异；不把两者相加。差异超过10%时复核订单口径与验收。

## PS与历史Band

`总市值(t)=不复权收盘价(t)×当日总股本(t)`。本实现限单一人民币A股股价可代表总股本的公司；多币种/多类别股份需先扩展分股类市值汇总，不可直接套用。

- 不把当前股本回填历史；增发、激励归属、回购注销、送转需逐项定位。解禁通常只改变流通股，不改变总股本。股本登记日与披露日之间无法核实的交易日排除并记录，不用旧股本填补。
- 交易日、行情时刻、公告可见时间分别记录。只有公告日期时，历史回放保守地从下一日（实际取下一交易日）起使用；当日分析可以使用截至分析时间已经阅读的最新报告，但不声称当日收盘前已可见。
- `TTM=上年FY+当年累计-上年同期累计`；季末不是可用日期。保留快报、正式报告及更正版本，不将后来重述数据回写到旧日期。快报金额精度不同，保留其原精度。
- `Forward PS(next calendar FY)=当前总市值/下一自然年预测收入`；下一年、当年FY、NTM须明确分开。
- 历史TTM Band只与当前TTM PS比较。输出起止日、样本数、缺失/排除日、10/25/50/75/90分位、当期TTM口径分位。局部窗口不得称上市全历史分位。
- 历史Forward Band必须有**当时冻结的预测版本**，按当时可见日期连接，同为下一自然年、相近预测时距（当前程序保守筛同一自然季度），并复核成长阶段和产品结构。禁止用后来实际收入或今天的预测倒填。
- 没有历史预测版本时，Forward Band=null，直接说明不可比较。不能因为2027 Forward PS低于历史TTM中位数就得出便宜结论。
- 固定倍数敏感性网格是分析师假设，不能伪装成历史分位或公允估值。TTM历史Band可画价格轨道：`分位倍数×当时可见TTM收入/当日股本`；不把它自动转为2027目标价。
- PS对低毛利、高研发和现金消耗敏感。北方华创、中微公司等盈利成熟公司同时交叉核验PE/经营现金流；多业务公司分部收入与合并收入必须勾稽，不能直接平移中科飞测倍数。

## 增长与倍数归因

对同一目标年度、同一收入定义：`V=R×PS`。

精确、无重复的收入优先拆解：

- 增长贡献`(R1-R0)×PS0`；
- 倍数贡献`R1×(PS1-PS0)`（含交互项）；
- 两项之和严格等于`V1-V0`。

股价另满足`P1/P0=(R1/R0)×(PS1/PS0)×(股本0/股本1)`。新增股份融资带来的现金不在PS拆解中，不能把全额市值变化解释为老股东收益。年度滚动时先保留共同预测年度，不能把2027换为2028所增加的收入全记为预测上调。

## 每次财报更新与证伪

1. 保留原输入、结果、预测目标年及模型/数据哈希，再建立新日期版本，不覆盖旧假设。
2. 追加实绩和来源；检查累计与单季、合并与母公司、原始与修订口径；重新核对股份事件和行情日期。
3. 列出新证据→仅受影响的假设→收入修订→Forward PS变化→倍数变化→结论变化；没有证据不得仅随股价调收入。
4. 将实际季度收入、毛利率、研发费率、经营现金流与上一版本逐项比较。收入误差=(实际-原预测)/原预测；绝对误差>10%、毛利率偏差>3pp、研发费率偏差>5pp触发复核。这些是可调整的分析师阈值，尚未经回测最优化。
5. 若合同负债上升而两期验收/收入放缓，检查验收积压与取消；若毛利率改善但扣非亏损扩大，检查研发和费用；若回款增长但CFO恶化，检查采购、存货及税费返还。避免只选择支持旧论点的指标。
6. 新报告使一个核心输入不可验证时保留null并降低结论等级；数据硬错误直接退出，不生成伪精确结果。

## 运行与迁移

```
python3 scripts/earnings_valuation.py assets/valuation/688361/model.json --output-dir output/688361
python3 -m unittest discover -s tests -v
```

脚本离线、只用Python标准库。输出result.json、quarterly_actuals.csv、historical_ps.csv、sensitivity.csv；输入/价格/代码哈希写入结果。`--previous-result`比较同一目标年的旧结果，跨目标年会拒绝。

复制数据结构到新公司目录，替换ticker、原始报表、公告日期、股本事件、价格、季度季节性与情景，依照[valuation-update-template.md](valuation-update-template.md)记录更新。公司池不提供默认增长或默认PS。先运行数据校验，再复核经济假设；脚本验证不等于证据真实性验证。

本次案例见[中科飞测验证](../assets/valuation/688361/validation-case.md)。原始PDF不打包公开；保留URL、页码与哈希供重新取得原件后复核。

后续2027年实绩发布后，可运行 `python3 scripts/score_forecast.py assets/valuation/688361/vintages/2026-10-30.json 新日期model.json --output-file output/score.json`。只评分已披露目标年单季度收入，未披露保留待验证；年度毛利率/研发敏感性需与同期间全年数据复核。

`sensitivity.csv`内的增长/倍数桥是从当前FY基准估计向下一FY情景推移，属于持有期敏感性；`--previous-result`才是同目标年度的版本修订归因。二者不得混称。
